# PULSE-8 | Professional Web Groovebox & Synth Studio 🎛️⚡

> **PULSE-8** — это полноценная звуковая рабочая станция и грувбокс в браузере. Построена на чистом нативном **Web Audio API** с нулевой задержкой, синтезом ударных и баса в реальном времени, 16-шаговой матрицей, полифоническим синтезатором, рэком мастер-эффектов и прямым экспортом в студийный несжатый 16-битный WAV.

## 🚀 Основные возможности

### 🥁 1. 16-шаговый секвенсор (6 дорожек)
- **Kick 909**: глубокая аналоговая бочка с экспоненциальным частотным спадом и щелчком.
- **Snare 808**: хлёсткий белый шум с полосовой фильтрацией и тональным телом барабана.
- **Hat Closed & Hat Open**: металлический синтезированный звук тарелок с удушением (choke group).
- **808 Sub-Bass**: скользящий суб-бас с настраиваемыми нотами на каждом активном шаге (`C1`–`F2`).
- **Lead Synth**: мелодический инструмент с выбором высоты тона для каждого шага (`C4`–`E5`).
- Индивидуальные регуляторы для каждого трека: **Mute** (M), **Solo** (S), громкость и предпрослушивание кликом по иконке.

### 🎹 2. Полифонический синтезатор и виртуальная клавиатура
- **2 полные октавы** с поддержкой мыши, тачскрина и **клавиатуры компьютера** (`A`, `W`, `S`, `E`, `D`, `F`, `T`, `G`, `Y`, `H`, `U`, `J`, `K`...).
- Переключение базовой октавы (`OCT 1` – `OCT 6`).
- Формы волны: **Sawtooth**, **Square**, **Sine**, **Triangle**.
- Отдельный **Sub-осциллятор** для плотного басового низа.
- Полная огибающая **ADSR**: Attack, Decay, Sustain, Release.
- Резонансный фильтр синтезатора с регулировкой среза (Cutoff) и резонанса (Q).

### 🎚️ 3. Рэк мастер-эффектов (Master FX Rack)
- **Master Filter**: переключение между Lowpass (LP) и Highpass (HP), частота от 20 Гц до 18 000 Гц, резонанс до 15 Q.
- **Stereo Delay / Echo**: регулировка задержки в миллисекундах и баланса Wet/Dry.
- **Saturation & Space**: аналоговая сатурация (теплый ламповый овердрайв) и алгоритмическая реверберация.
- **Live Glitch пэды**: зажмите кнопки `1/8`, `1/16` или `1/32` для моментального повтора бита (stutter roll) во время живого выступления.

### 📊 4. 60 FPS аудио-визуализатор
- **Waveform (Осциллограф)**: лазерная форма волны с определением пересечения нуля для стабильной картинки.
- **32-Band Spectrum**: анализатор спектра с удержанием пиковых значений.
- **Radial Pulsar**: круговой реактивный пульсар для мощных дропов.
- Два индикатора пиковых уровней стереоканалов (**L / R**).

### ⚡ 5. Встроенные стили и алгоритмический генератор
- **Cyberpunk 2077** (130 BPM, Darksynth)
- **Neo French House** (124 BPM, Disco / House)
- **Midnight Lo-Fi** (85 BPM, Chillhop Boom-Bap)
- **Acid 303 Core** (138 BPM, Acid Techno)
- Кнопка **Mutate Beat** — алгоритмически создаёт свежую гармоничную ритмическую партию в один клик.

### 💾 6. Экспорт в WAV
- Кнопка **Export WAV** рендерит мастер-луп в оффлайн-контексте со всеми эффектами и автоматически скачивает готовый файл `pulse8_beat_[style]_[bpm]bpm.wav` на ваш компьютер или телефон.

## 🛠️ Как запускать проект

### Вариант 1: Прямо в браузере (без установки)
Приложение уже развернуто на облачном сервере:
- **Ссылка разработчика**: доступна в панели Google AI Studio (кнопка *Preview* или иконка браузера).
- **Публичная ссылка**: можно скопировать из строки `Shared App URL` и открыть на любом телефоне, планшете или компьютере.

---

### Вариант 2: Запуск локально на своем компьютере через Git

#### Требования:
- Установленный **Node.js** (версия 18+ или 20+)
- Установленный **Git**

#### Шаги:

1. **Клонируйте репозиторий с вашего GitHub(или скачай проект):**
   ```bash
   git clone https://github.com/gorghazaryan2011gor-hash/Pulse8.git
   cd Pulse8
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес:
   ```
   http://localhost:3000
   ```

## ⌨️ Горячие клавиши (Hotkeys)

| Клавиша | Действие |
|---|---|
| **Space (Пробел)** | Запуск / Пауза воспроизведения |
| **Кнопка TAP** | Настукивание собственного темпа BPM пальцем |
| **A, W, S, E, D, F, T, G, Y, H, U, J, K** | Игра на нотах синтезатора (белые и чёрные клавиши) |
| **Shift / Right Click** | Выбор высоты ноты для шагов баса и синтезатора в секвенсоре |

## 🏗️ Стек технологий

- **Фреймворк**: React 19, TypeScript
- **Сборщик**: Vite 8
- **Стилизация**: Tailwind CSS 4, Lucide Icons
- **Звуковой движок**: Web Audio API (AudioContext, OscillatorNode, BiquadFilterNode, ConvolverNode, DelayNode, WaveShaperNode, OfflineAudioContext)
- **Кодировщик**: встроенный TypeScript RIFF WAV Encoder (чистый PCM)
